# 쌀가루집안 홈페이지

쌀가루집안 방송을 소개하고 공지사항과 방송 일정을 직접 관리할 수 있는 Next.js 기반 웹사이트입니다. 방문자는 최신 하이라이트 영상과 공지, 방송 계획을 한눈에 확인할 수 있고, 관리자 페이지에서 손쉽게 콘텐츠를 작성할 수 있습니다.

## 주요 기능

- **맞춤 메인 화면**: 하이라이트 YouTube 영상을 강조하고 공지·일정을 동시에 확인할 수 있는 다크 테마 레이아웃
- **멤버 사이드바**: 멤버 프로필을 자유롭게 관리하여 원하는 구성원을 사이드바에 노출할 수 있습니다.
- **공지/일정 보드**: 관리자 페이지에서 등록한 내용이 실시간으로 반영되어 방문자에게 안내됩니다.
- **관리자 페이지**: 비밀번호 기반 인증 후 공지, 일정, 멤버, 하이라이트 영상을 직접 추가/수정/삭제할 수 있습니다.

## 관리자 페이지 사용법

1. 환경 변수 `ADMIN_PASSWORD`에 원하는 관리자 비밀번호를 설정합니다. (설정하지 않으면 `ssalgageul-family`가 기본값입니다.)
2. `/admin` 주소로 접속한 뒤 비밀번호를 입력하면 관리자 대시보드에 접근할 수 있습니다.
3. 대시보드에서 하이라이트 영상, 공지, 방송 일정, 멤버를 관리하면 내용이 로컬 스토리지에 저장되고 홈페이지에 즉시 반영됩니다.
4. **보안 주의**: 이 프로젝트는 별도의 서버 데이터베이스 없이 브라우저 로컬 스토리지를 사용하므로 공개 배포 시에는 백엔드 연동을 고려하세요.

## 개발 & 실행

```bash
pnpm install
pnpm dev
```

### 스크립트

- `pnpm dev` – 개발 서버 실행
- `pnpm build` – 프로덕션 빌드
- `pnpm start` – 빌드 결과 실행
- `pnpm lint` – ESLint 검사 (초기 실행 시 Next.js가 ESLint 설정 생성을 제안할 수 있습니다.)

## 기술 스택

- Next.js 14 (App Router) & TypeScript
- Tailwind CSS, next-themes
- 로컬 스토리지 기반 클라이언트 데이터 관리

## 프로젝트 구조

```
src/
  app/
    page.tsx          // 쌀가루집안 메인 페이지
    admin/            // 관리자 로그인/대시보드
    api/admin/login   // 로그인/로그아웃 API
    members/          // 멤버 목록 및 상세 페이지
  components/
    admin/            // 관리자 전용 컴포넌트
    home/             // 메인 화면 전용 컴포넌트
    members/          // 멤버 전용 컴포넌트
  hooks/
    use-stored-members.ts // 로컬 스토리지 기반 멤버 로더
  lib/
    auth.ts           // 관리자 인증 유틸리티
    site.ts           // 사이트 메타데이터 설정
    storage.ts        // 로컬 스토리지 키 모음
    members.ts        // 멤버 데이터 정규화 유틸리티
  types/
    stored-member.ts  // 로컬 스토리지에 저장되는 멤버 타입
```

## 배포 메모

- 관리자 데이터는 브라우저 로컬 스토리지에 저장되므로 동일한 브라우저/기기에서 유지됩니다.
- 멀티 사용자 환경이나 영구 저장이 필요하면 별도의 데이터베이스 또는 서버 API 연동이 필요합니다.
- `ADMIN_PASSWORD` 환경 변수는 빌드/실행 환경에서 안전하게 관리하세요.
